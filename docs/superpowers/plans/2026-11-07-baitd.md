# Baitd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, cross-platform Python app with a browser UI that turns a topic (or a list of topics) into finished, hook-driven 9:16 / 16:9 HD short videos with AI script, stock clips, TTS voice, word-synced burned subtitles and background music.

**Architecture:** A Flask server bound to `127.0.0.1` serves a single-page UI and a small JSON API. A job pipeline (script → voice → clips → shot timeline → captions → render) runs in a background worker thread fed by a persisted queue. All media work is done by the FFmpeg binary bundled through `imageio-ffmpeg`, driven by subprocess. Providers (LLM, TTS, stock) are small modules behind one function signature each.

**Tech Stack:** Python ≥ 3.10, Flask, requests, edge-tts 7.3.x, imageio-ffmpeg 0.8.x (FFmpeg 9 with libass, loudnorm, sidechaincompress), platformdirs, pytest, PyInstaller, GitHub Actions. Front end: plain HTML/CSS/JS, no build step.

**Spec:** `docs/diseno-2026-11-07.md` (Spanish). Executors read it alongside this plan.

## Global Constraints

- Python ≥ 3.10; runs on Windows, macOS (Intel + Apple Silicon) and Linux.
- Server listens on `127.0.0.1` only. API keys are sent only to the service they belong to.
- FFmpeg comes from `imageio_ffmpeg.get_ffmpeg_exe()`; never require a system FFmpeg. There is no ffprobe: probe with `ffmpeg -i` and parse stderr.
- Output: 1080×1920 (9:16) or 1920×1080 (16:9); 30 fps by default or 60; constant frame rate; H.264 `yuv420p`, CRF ≈ 18 (libx264) or equivalent quality on hardware encoders; AAC ≥ 192 kbps at 48 kHz; `+faststart`.
- Voice loudness ≈ −14 LUFS (`loudnorm=I=-14:TP=-1.5:LRA=11`); music ducked under voice; 1.5 s music fade-out.
- Maximum upscale of the visible crop is 1.25×, including the slow zoom (zoom goes 1.00 → 1.08 over a shot).
- Image changes every 2.0–4.0 s; no clip repeats within one video; hook (first sentence) said within 1–3 s.
- Captions: word-by-word highlight, chunks of 1–4 words, ≤ 150 ms off the voice, inside the platform safe zone, hook chunk 1.25× bigger.
- Full caption quality for Latin-script languages. Other scripts: phrase-level captions with a fallback font, no RTL guarantee.
- Bundled assets must allow redistribution: music CC0 / public domain, fonts OFL. License of the project: MIT.
- User data (settings, keys, profiles, queue, clip cache, user music, outputs) lives in `platformdirs.user_data_dir("Baitd")` unless the user picks another output folder. Never inside the app bundle.
- Every user-facing error states the cause and the fix, e.g. `Falta la clave de Pexels → Ajustes`.
- UI strings live in `i18n/es.json` and `i18n/en.json`. No hard-coded copy in JS/HTML.
- Windows long-path pitfall: the repo must sit in a short path (e.g. `C:\proyectos\baitd`). Venv creation fails under very deep paths.

## Review Focus

1. **Missing, wrong or rate-limited API key, or network drop mid-job.** The job ends with a readable `cause → fix` error, temp files are removed, and a batch moves on to the next topic. Tests: Task 3 `test_provider_http_error_message`, Task 5 `test_missing_key_message`, Task 11 `test_batch_continues_after_failure`.
2. **LLM returns malformed JSON, prose around the JSON, the wrong length or missing keywords.** Strip code fences, retry once with a repair prompt, then fail clearly. Tests: Task 3 `test_parse_script_with_fences`, `test_parse_script_rejects_missing_keywords`, `test_generate_retries_once`.
3. **No clip passes the quality bar for a keyword.** Fall back through next keyword → generic term → photo with Ken Burns, never exceeding 1.25× upscale. Test: Task 5 `test_select_falls_back_to_photo`.
4. **Non-ASCII and spaces in topics and in the OS user path** ("José", "¿Por qué?", emoji). Output folder slug is safe, and the ASS path is not broken by FFmpeg filter escaping (run FFmpeg with `cwd` = job dir and a relative `subs.ass`). Tests: Task 2 `test_slugify_unicode`, Task 9 `test_render_in_path_with_spaces_and_accents`.
5. **User cancels or closes the app mid-render.** FFmpeg is killed, partial outputs removed, and the queue item is marked `cancelled`, or `pending` again after an app restart. Tests: Task 9 `test_render_cancel_kills_ffmpeg`, Task 11 `test_queue_restores_running_as_pending`.

**Files:** Create `src/baitd/captions.py`, `tests/test_captions.py`; add the OFL fonts to `src/baitd/assets/fonts/`

Hook chunks use `\fscx125\fscy125`. When `is_latin` is false, emit phrase-level lines without per-word highlight, using Noto Sans. FFmpeg finds fonts through `ass=subs.ass:fontsdir=fonts`.
