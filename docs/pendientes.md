# Baitd: pendientes

Lista de cambios pedidos que todavía no se hacen. Cuando se haga uno, se borra de aquí.

## Sin probar todavía

1. Clipping completo (pasos 3 a 5: momentos con IA, encuadre y render) con un video real y una clave de Gemini.
2. Las apps de Mac y Linux en una máquina real.
3. Pasar un bloqueo real de YouTube usando cookies reales (Ajustes → Clipping → Sesión de YouTube).
4. La actualización real entre dos Releases publicadas: la instalación silenciosa con `/UPDATE=1` y que Baitd se vuelva a abrir solo. No se puede comprobar hasta que exista la 0.3.1 o una versión posterior.
5. Probar si el Baitd que se reabre tras una actualización necesita `PYINSTALLER_RESET_ENVIRONMENT=1`.
6. Que el instalador borre los archivos viejos de `_internal` al actualizar (`[InstallDelete]`).
7. Borrar el instalador descargado cuando ya no hace falta.
8. Un cookies.txt guardado que luego se borra no debería impedir guardar otros ajustes.
